# CellLabel

Downloads for CellLabel, the cell counting app for Olympus cellSens slide scans.
Get the latest version from [Releases](https://github.com/mbc210/celllabel-releases/releases/latest),
or from [celllabel.com](https://celllabel.com).

## Licence

CellLabel is free for academic research, teaching and private study. Companies need a
separate licence. To ask for one, [open an issue](https://github.com/mbc210/celllabel-releases/issues).
The full terms are in [LICENSE](LICENSE).

The TrueTH model that ships with CellLabel has its own licence, the GNU GPL version 3. The
licence text, the model's source and the script that converted it are in
[models/trueth](models/trueth) and [scripts](scripts).

[THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) lists the other software CellLabel is
built on.

## Citing CellLabel

If you publish work that used CellLabel, please cite it. [CITATION.cff](CITATION.cff) has
the details. GitHub's "Cite this repository" button, on the right of this page, turns it
into APA or BibTeX.
